# Simple Express App

A basic Express.js application with simple API routes.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run the Server
```bash
npm start
```

The server will start on `http://localhost:3000`

## Available Routes

- `GET /` - Welcome message
- `GET /api/hello` - Hello message from API
- `POST /api/echo` - Echo back the request body
